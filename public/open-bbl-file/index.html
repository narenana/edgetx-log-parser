How to open a .bbl file (Betaflight & iNAV blackbox logs)

To open a .bbl file, drag it into RC Log Viewer in your browser — a .bbl is a blackbox log, the high-rate flight recording written by Betaflight or iNAV firmware. It parses locally with WebAssembly, so nothing is installed and the file is never uploaded. The same tool opens the related .bfl and .txt blackbox exports.

Double-clicking a .bbl does nothing because it isn't a document format — it's raw binary flight data with no default app registered to it. You need a viewer that decodes the blackbox stream, which is what this page walks through.

What a .bbl file actually is

A .bbl ("blackbox log") is a binary recording of your flight controller's internal state, sampled hundreds to thousands of times per second. Depending on how you got it, the same data may carry a different extension:

  • .bbl — a blackbox log pulled off an onboard dataflash chip or SD card.
  • .bfl — "Betaflight log", the same binary format under a different name.
  • .txt — some blackbox captures land with a .txt extension (for example a log written over serial to an onboard flash or OpenLog). Despite the extension it is not plain text; opening it in Notepad shows garbled binary.

All three are the same kind of blackbox stream and all three open the same way. A single .bbl can also contain more than one flight (several arm/disarm "log sessions" concatenated), and a good viewer will let you pick which one to look at.

Open and view your .bbl online — no install, no upload

Open RC Log Viewer and drop the file in:

  1. Go to https://www.narenana.com/log-viewer/.
  2. Drag your .bbl / .bfl / .txt file onto the page (or click to browse for it).
  3. The blackbox stream is decoded in-browser and your telemetry appears — attitude, altitude and vertical speed, speed and heading, battery, signal, and RC inputs, all synced to a scrubbable timeline.

Because parsing runs entirely client-side with WebAssembly, the file never leaves your machine. That matters for blackbox logs specifically: they embed the GPS coordinates of your flying field, and local parsing means those coordinates never get transmitted anywhere. You can also install the tool as an offline PWA, or grab the free desktop apps (Windows/macOS/Linux) from GitHub releases if you prefer opening logs without a browser tab.

Which firmware made my .bbl?

Two firmwares write blackbox logs, and it changes what you'll see:

BetaflightRacing and freestyle multirotors. Logs are dense with gyro, PID, motor, and RC data. Most quads fly without a GPS module, so a Betaflight .bbl usually has no GPS — the 3D globe stays unavailable, but every telemetry chart and the live telemetry bar still work.
iNAVFixed-wing and GPS-equipped craft. When a GPS module is fitted (typical on iNAV), the log includes position, so you also get the 3D flight replay on a satellite globe with chase, tail, orbit, and top-down cameras.

Not sure which you have? The blackbox header records the firmware type and revision, and RC Log Viewer reads it to decode the stream. As a rule of thumb: if it came off a quad tuned in Betaflight Configurator, it's Betaflight; if it came off a wing or a GPS build, it's likely iNAV. For a deeper walkthrough of each, see the Betaflight blackbox viewer and iNAV blackbox viewer pages.

Supported versions and limits

RC Log Viewer decodes iNAV blackbox up to 8.x and Betaflight blackbox up to 4.5.x. A few honest notes:

  • A .bbl with no GPS frames won't produce a 3D map — that's a property of the log, not the viewer. The charts and telemetry bar still give you the full picture.
  • A .txt blackbox capture is still the same binary and opens normally — don't try to read it as text.
  • If your log came from an EdgeTX/OpenTX radio's SD card, that's a different, human-readable CSV format, not blackbox — open it with the EdgeTX log viewer instead.

Frequently asked questions

What program opens a .bbl file?
A blackbox log viewer. You don't need to install anything — open RC Log Viewer at narenana.com/log-viewer and drag the .bbl in. It decodes Betaflight and iNAV blackbox logs in your browser.
Why does double-clicking my .bbl file do nothing?
Because .bbl isn't a document format with a default app registered to it — it's raw binary flight data. Windows and macOS don't know what to open it with. You need a dedicated blackbox viewer to decode the stream.
Is .bfl or .txt the same as .bbl?
Yes. .bfl is the same blackbox binary under a different name, and a .txt blackbox capture is a blackbox log despite the extension. All three open the same way in RC Log Viewer.
Do I have to upload my .bbl anywhere?
No. RC Log Viewer parses the file locally in your browser with WebAssembly. The log — including the GPS coordinates of your flying field — never leaves your machine.
My .bbl has no map — why?
The 3D globe needs GPS coordinates in the log. Betaflight quads usually fly without a GPS module, so their logs have no position data. The telemetry bar and every synced chart still work fully; iNAV logs with a GPS module do show the map.
How do I know if my log is from Betaflight or iNAV?
The blackbox header records the firmware type, and RC Log Viewer reads it when decoding your log. Generally, logs off a quad are Betaflight and logs off a fixed-wing or GPS build are iNAV.
