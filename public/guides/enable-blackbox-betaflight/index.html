How to enable Blackbox in Betaflight and download your log

To enable Blackbox in Betaflight: open Betaflight Configurator, go to the Blackbox tab, set the Blackbox logging device to your onboard flash chip or SD card, choose a logging rate, and click Save. Then arm and fly. Afterward, come back to the Blackbox tab, hit Download, and save the .bbl file.

That log holds gyro, PID, RC command, motor and battery data at a high sample rate. Most racing and freestyle quads log with no GPS, so a 3D map usually is not available — but every telemetry channel and synced chart still works in the RC Log Viewer.

Turn on logging in the Blackbox tab

Connect your flight controller to Betaflight Configurator over USB, then open the Blackbox tab in the left menu. There are three things to set:

  1. Blackbox logging device — choose where the log is written. If your FC has an onboard flash chip, pick Onboard flash. If it has an SD card slot, pick SD card. If you only stream Blackbox to an external device over serial, choose Serial, but flash/SD is by far the most common.
  2. Blackbox logging rate — this is the fraction of the PID loop that gets logged, shown as a ratio like 1/1, 1/2, or 1/4. 1/2 is a sensible default that captures clean gyro/PID traces without filling flash too fast. Drop to 1/4 if you have a small flash chip or want longer flights per log.
  3. Debug mode — leave it at NONE for normal PID/filter review. Set a specific debug mode (for example a gyro or RPM filter debug) only when you are chasing one particular issue, because it repurposes the debug channels for that data.

Click Save when done. Nothing is logged until this is set and the quad is armed.

Make sure there is room to log

Onboard flash is small — often just a few megabytes — so it fills fast, especially at 1/1 or 1/2. Before a session:

  • Check the Used space readout on the Blackbox tab. If it is near full, download anything you want to keep, then click Erase Flash to clear it.
  • An SD card gives you far more room and longer continuous logs than a flash chip, if your board has a slot.
  • Higher logging rate = more detail but shorter recording time per megabyte. Pick the rate that fits how long your flights are.

Betaflight logs continuously while armed and stops on disarm, so each arm/disarm cycle is one log segment.

Arm, fly, then download the .bbl

Once logging is configured, just fly normally — logging starts automatically on arm. After you land and disarm:

  1. Plug the FC back into USB and open Betaflight Configurator (do not erase yet).
  2. Go to the Blackbox tab and click Download. On SD-card boards you can also pull the card and copy the file directly.
  3. Save the file — Betaflight writes it as a .bbl. A single file can hold several arm/disarm segments concatenated from one session. Some tools also produce .bfl or .txt variants; all three are the same blackbox format.

Keep the file somewhere you can find it — that is the file you will open to review the flight.

Open the .bbl to check it recorded

To confirm the log came out clean, drop the .bbl straight into the RC Log Viewer. It parses the file locally in your browser with WebAssembly — the log is never uploaded, which matters because a blackbox file embeds the GPS coordinates of your flying field whenever GPS is present. No account, nothing to install.

The viewer reads Betaflight blackbox up to 4.5.x. If your quad has no GPS — typical for racing and freestyle builds — the 3D globe is unavailable, but the telemetry bar and every synced chart still work. For what each trace actually means once the log is open, see how to read a blackbox log, or open the quad sample log to poke around first.

Frequently asked questions

Where is the Blackbox setting in Betaflight?
In Betaflight Configurator, click the Blackbox tab in the left-hand menu. That is where you set the logging device, logging rate, and debug mode, and where you later download or erase logs.
What logging rate should I use?
1/2 is a good default — it captures clean gyro and PID traces without filling flash too quickly. Use 1/4 for a small flash chip or longer flights, or 1/1 for maximum detail if you have SD-card space.
Why is there no map when I open my Betaflight log?
Most racing and freestyle quads have no GPS module, so the log contains no coordinates and the 3D globe can't be drawn. The telemetry bar and every synced chart still work. If you fly a build with GPS, position data will be present.
What file does Betaflight save, and what extension?
Betaflight writes a blackbox log with the .bbl extension. You may also see .bfl or .txt variants from some tools — they are the same blackbox format and all open in the viewer.
Do I need to set a debug mode?
No. Leave debug mode at NONE for normal PID and filter review. Only select a specific debug mode when you are troubleshooting one particular thing, since it repurposes the debug channels for that data.
Is my flying-field location safe when I open the log?
Yes. RC Log Viewer parses the file entirely in your browser — nothing is uploaded. If GPS coordinates are in the log, they never leave your machine.
